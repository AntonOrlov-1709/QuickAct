# Акт за 5 минут (QuickAct)

Пользователь: арендатор 20–23 лет, студент старших курсов или начинающий специалист. Впервые снимает квартиру сам, без юриста и часто без риелтора. Пользуется сервисом при каждом въезде, то есть раз в год-два. Сервис работает в браузере телефона, ставить приложение не нужно.

Роли:
- Арендатор — снимает квартиру на видео, проверяет найденные дефекты, собирает акт и отправляет его собственнику.
- Собственник — открывает акт по ссылке без регистрации, по каждому пункту ставит «согласен» или «возражаю» с комментарием и подтверждает акт целиком.

Зачем: при въезде зафиксировать состояние квартиры так, чтобы собственник это подтвердил. Тогда при выезде он не сможет удержать залог за дефекты, которые были до жильца.

Ключевой сценарий: арендатор входит → создаёт осмотр (адрес, номер договора, ФИО собственника) → по комнатам снимает видео по подсказкам → ИИ находит на видео дефекты и предлагает пункты акта → арендатор проверяет пункты, правит их, добавляет пропущенное вручную и ставит степень износа → вводит показания счётчиков → проверяет акт и пункт для договора → отправляет ссылку собственнику → собственник отмечает каждый пункт и подтверждает → арендатор видит статус «подтверждён» или «есть возражения».

Экраны:
1. Мои осмотры — список актов со статусами.
2. Съёмка — видео комнаты с подсказками, что снять, и список «Что снято».
3. Проверка дефектов — пункты, найденные ИИ, с кадрами из видео; правка, удаление, ручное добавление, счётчики.
4. Акт — итоговый документ, пункт для договора, отправка собственнику.
5. Акт для собственника — страница по ссылке: согласие или возражение по пунктам, подтверждение.

Основная сущность: акт осмотра — адрес, номер договора, ФИО собственника, дата, статус (черновик / отправлен / подтверждён / есть возражения), видео по комнатам, показания счётчиков, пункты. Пункт акта: комната, кадр из видео, описание, степень износа (1–5), источник (ИИ / вручную), решение собственника, комментарий.

LLM-функция: поиск дефектов на видео. Из видео комнаты берутся кадры, модель находит на них дефекты и для каждого предлагает пункт акта: комнату, тип дефекта, нейтральное описание, степень износа и кадр-доказательство. Арендатор всегда проверяет и правит результат до отправки.

Не в этом курсе: вход и подтверждение по SMS, распознавание счётчиков камерой (вводятся вручную), правило 48 часов, юридически значимая подпись, допсоглашение к подписанному договору, сценарий выезда со сравнением «до» и «после», платежи.
